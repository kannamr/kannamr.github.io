Personalized static portfolio for GitHub Pages, highlighting résumé-backed experience in AWS, Kubernetes, Terraform, CI/CD, security automation, observability, and cloud cost optimization.

## Publish on GitHub Pages
1. Create a public repository named `kannamr.github.io` for a user site.
2. Upload the contents of this folder so `index.html` is at the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, and save.
5. Once deployment finishes, visit `https://kannamr.github.io/`.
